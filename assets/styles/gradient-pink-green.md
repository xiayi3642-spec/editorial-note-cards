# 风格：粉绿渐变（可选风格）

- 名称：`gradient-pink-green`
- 默认：否（用户给粉/青绿系渐变参考图，或点名「粉绿」时使用）
- 来源参考色：`#F9D2E4`（浅粉）、`#67C9B5`（青绿）、`#007E79`（深绿）
- 氛围：柔和生机 —— 浅粉→青绿→深绿 **对角渐变**（左下浅→右上深）+ 奶油卡浮层
- 文字明暗：**外层文字与描边固定白色**；内容卡白底 → 正文用深色

## 色板（按 7:2:1 + 同色系延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景对角渐变 | `linear-gradient(to top right,#F9D2E4 0%,#CFE8DF 30%,#9BDCC9 55%,#67C9B5 78%,#007E79 100%)` | 画布底，左下浅→右上深（同色系延伸 5 阶） |
| `--accent` | `#67C9B5` | 青绿强调（kicker、序号、lead、quote 边） |
| `--ink` | `#007E79` | 正文深绿（卡内白底深字） |
| `--gray` | `#8FB5AA` | 次要灰 |
| `--cream` | `#FFF6FB` | 卡片底（偏粉白） |
| `--edge` | `#67C9B5` | 卡片青绿细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 固定白色（frame/t1/t2/bot/rule/foot） |
| 封面文字 | 白 `#fff` | 渐变上白字 |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
