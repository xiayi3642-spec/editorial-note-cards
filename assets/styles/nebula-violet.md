# 风格：星云紫夜（可选风格）

- 名称：`nebula-violet`
- 默认：否（用户给「星云蓝紫夜空」参考图，或点名「星云紫夜」时使用）
- 来源参考色：神麵色卡·星云紫 —— 背景整体蓝紫星云夜空；主色（箭头色块）亮紫 `#800CF2`；色板 浅紫/亮紫/灰紫/深蓝紫/深蓝黑
- 氛围：星云紫夜 —— 深邃蓝紫夜空渐变 + **奶油白卡浮层**（卡底沿用定稿奶油白 `#FAF6E8`，与绿色 Editorial 同构）
- 文字明暗：**整体深色 → 外层文字与描边统一白；内容卡浅底 → 正文用深色**

## 色板（按 7:2:1 + 同色系延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景渐变 | `linear-gradient(180deg,#050E1B 0%,#4B478C 55%,#625EA1 100%)` | 画布底，整体深蓝紫夜空 |
| `--accent` | `#800CF2` | 亮紫强调（kicker、序号、lead、quote 边） |
| `--ink` | `#1E1B4B` | 正文深紫蓝（卡内浅底深字） |
| `--gray` | `#8E8AC0` | 次要灰 |
| `--cream` | `#FAF6E8` | 卡片底（奶油白，定稿沿用） |
| `--edge` | `#800CF2` | 卡片亮紫细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 整体深 → 外层全白，页脚白 `rgba(255,255,255,.92)` |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
