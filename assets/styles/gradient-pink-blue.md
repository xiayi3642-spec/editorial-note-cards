# 风格：粉蓝紫渐变（可选风格）

- 名称：`gradient-pink-blue`
- 默认：否（用户给粉/蓝/紫系渐变参考图，或点名「粉蓝紫」时使用）
- 来源参考色：`#FFCEE3`（浅粉）、`#678EC9`（蓝）、`#262277`（深蓝紫）
- 氛围：现代清新 —— 浅粉→蓝→深蓝紫 **对角渐变**（左下浅→右上深）+ 奶油卡浮层
- 文字明暗：**外层文字与描边固定白色**；内容卡白底 → 正文用深色

## 色板（按 7:2:1 + 同色系延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景对角渐变 | `linear-gradient(to top right,#FFCEE3 0%,#D9D5F0 30%,#9BAEDF 55%,#678EC9 78%,#262277 100%)` | 画布底，左下浅→右上深（同色系延伸 5 阶） |
| `--accent` | `#678EC9` | 蓝强调（kicker、序号、lead、quote 边） |
| `--ink` | `#262277` | 正文深蓝紫（卡内白底深字） |
| `--gray` | `#8A8FB0` | 次要灰 |
| `--cream` | `#FFF7FB` | 卡片底（偏粉白） |
| `--edge` | `#678EC9` | 卡片蓝细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 固定白色（frame/t1/t2/bot/rule/foot） |
| 封面文字 | 白 `#fff` | 渐变上白字 |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
