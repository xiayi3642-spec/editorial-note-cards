# 风格：赤霞绯梦·红粉（可选风格）

- 名称：`gradient-serene`
- 默认：否（用户给红/浅粉系渐变参考图，或点名「赤霞绯梦」时使用）
- 来源参考色：`#FF7374`（红）、`#FDB5E3`（浅粉）—— 原图 04 Serene Horizon
- 氛围：暖霞绯粉 —— 右上红 → 左下浅粉 对角渐变 + 奶油卡浮层，与绿色 Editorial 同构
- 文字明暗：**深色在右上/顶部 → 顶部外层文字与描边用白；底部浅区页脚用深色；内容卡浅底 → 正文用深色**

## 色板（按 7:2:1 + 同色系延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景对角渐变 | `linear-gradient(to bottom left,#FF7374 0%,#FF9C9E 45%,#FDB5E3 100%)` | 画布底，右上深→左下浅 |
| `--accent` | `#FF7374` | 红强调（kicker、序号、lead、quote 边） |
| `--ink` | `#8E3247` | 正文深红（卡内浅底深字） |
| `--gray` | `#C08A98` | 次要灰 |
| `--cream` | `#FFF4FA` | 卡片底（偏浅粉白） |
| `--edge` | `#FF7374` | 卡片红细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 右上/顶部深区白；左下浅区页脚用 `#8E3247` |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
