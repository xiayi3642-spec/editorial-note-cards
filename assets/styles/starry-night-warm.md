# 风格：星夜暖暮（可选风格）

- 名称：`starry-night-warm`
- 默认：否（用户给「星空夜空 → 暖黄」渐变参考图，或点名「星夜暖暮」时使用）
- 来源参考色：神麵色卡·星空夜景 —— 背景上深蓝夜空 → 中段蓝紫 → 下暖黄；主色（箭头色块）豆沙粉 `#DAADA9`；色板 深灰蓝/灰紫/豆沙粉/浅米黄/暖黄
- 氛围：星夜暖暮 —— 顶部深蓝夜空 + 流星星点 → 底部暖黄 垂直渐变 + 浅暖米色卡浮层，与绿色 Editorial 同构
- 文字明暗：**深色在上方 → 顶部外层文字与描边用白；底部浅暖区页脚用深色；内容卡浅底 → 正文用深色**

## 色板（按 7:2:1 + 同色系延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景渐变 | `linear-gradient(180deg,#1E2A3F 0%,#65608D 40%,#DAADA9 72%,#FCF3C9 100%)` | 画布底，上深蓝夜空→下暖黄 |
| `--accent` | `#DAADA9` | 豆沙粉强调（kicker、序号、lead、quote 边） |
| `--ink` | `#1E2A3F` | 正文深蓝（卡内浅底深字） |
| `--gray` | `#7A7AA6` | 次要灰 |
| `--cream` | `#FDF6EA` | 卡片底（浅暖米） |
| `--edge` | `#DAADA9` | 卡片豆沙粉细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 顶部深夜空区白；底部浅暖区页脚用 `#1E2A3F` |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
