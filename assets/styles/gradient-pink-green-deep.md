# 风格：粉绿深调渐变（可选风格）

- 名称：`gradient-pink-green-deep`
- 默认：否（用户给粉/青绿系渐变参考图，或点名「粉绿深调」时使用）
- 来源参考色：`#F9D2E4`（浅粉）、`#67C9B5`（青绿）、`#007E79`（深绿）—— 深调延伸
- 氛围：沉静青绿 —— 左下浅粉 → 右上深绿 对角渐变 + 奶油卡浮层，与绿色 Editorial 同构
- 文字明暗：**右上深色区 → 外层文字与描边固定用白；内容卡浅底 → 正文用深色；左下浅区页脚用深色**

## 色板（按 7:2:1 + 同色系深调延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景对角渐变 | `linear-gradient(to top right,#DDBBD9 0%,#9FC7BC 30%,#4FA999 55%,#2C8C7C 78%,#00645E 100%)` | 画布底，左下浅→右上深 |
| `--accent` | `#4FA999` | 青绿强调（kicker、序号、lead、quote 边） |
| `--ink` | `#00645E` | 正文深绿（卡内浅底深字） |
| `--gray` | `#6FA89C` | 次要灰 |
| `--cream` | `#F2F8F4` | 卡片底（偏白绿） |
| `--edge` | `#2C8C7C` | 卡片青绿细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 右上深区固定白（frame/t1/t2/rule）；左下浅区页脚用 `#00645E` |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
