# 风格：秋冬红治愈（Autumn Red Cozy）

- 名称：`autumn-red-cozy`
- 默认：否（参考图驱动；暖调治愈系 / 生活方式类笔记启用）
- 氛围：奶油米白卡面 + 砖红主字 + 藏蓝正文 + 暖橙黄点缀，秋冬暖而不沉，治愈感强
- 文字明暗：外层深底 → 白框白字；奶油卡内 → 藏蓝字

## 色板（参考图反推 7:2:1）
| token | 值 | 用途 |
|---|---|---|
| 背景渐变 | `linear-gradient(160deg,#2B2C4A 0%,#5E3240 36%,#9E2A2B 68%,#D99A55 100%)` | 画布外层（藏蓝 → 砖红 → 暖砂） |
| `--accent` | `#9E2A2B` | 砖红：kicker、序号、kv 标签、lead 强调、卡片细边 |
| `--ink` | `#33345B` | 藏蓝：标题与正文墨色 |
| `--gray` | `#7A6F66` | 暖灰：次要文字 |
| `--cream` | `#FFF2DF` | 奶油米白卡底（参考图主底色） |
| `--edge` | `#9E2A2B` | 卡片砖红细边 |
| `--highlight` | `#F6AE45` | 暖橙黄荧光笔（红蓝主色的高饱和对比暖色） |
| 白 | `#fff` / `rgba(255,255,255,.9)` | 封面文字、外层白框 |

## 参考图原始色值
- 奶油米白 `#FFF2DF` · 暖橙黄 `#F6AE45` · 砖红 `#9E2A2B` · 藏蓝 `#33345B` · 外圈近黑 `#161313`（装饰边，未入卡片体系）

## 荧光笔
- 颜色 `#F6AE45`（暖橙黄），高度/位置/透明度走全局默认（70% / +3px / .4）。
- CSS 覆盖：`:root{--highlight:#F6AE45;}`

## 字体栈
- 中文正文/标题：Noto Serif SC（宋体衬线）
- 英文大标题/序号：Playfair Display
- kicker/标签/页脚：IBM Plex Mono
- 顶部栏：Noto Sans SC
- 全局 `font-style:normal`

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框 `inset:24px` + `.t1/rule/.t2/.bot`
- 卡片 `top:190px / bottom:136px`；卡内顶部三处间距 h1 34 / sub 8 / body 16
- 封面：渐变底 + 外层白框 + 居中白字；内容卡奶油浮层、foot 吸底
