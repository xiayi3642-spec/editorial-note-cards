# 风格：立冬（可选风格）

- 名称：`lidong`
- 默认：否（用户上传淡蓝雪景/立冬参考图，或点名「立冬」「冬日雪景」时使用）
- 来源参考：小红书「小美说·遇见立冬」海报——淡蓝雾感冬日雪景，覆雪光秃树枝、飘落六角雪花、雪坡白线轮廓、细腻雪粒颗粒
- 氛围：清冷烟火 —— 浅冰蓝噪点底图 `media/bg-lidong.jpg`，上部落雪树枝与雪花，下部雪坡留白；**同一张垫图封面与内容页通用**，封面浅底深字
- 文字明暗：**浅底深字**（冰蓝底 → 深蓝墨字，封面上半部文字直接压雪景，无罩层、无 text-shadow）

## 色板（按 7:2:1 + 从参考图取色）
| token | 值 | 用途 |
|---|---|---|
| 背景垫图 | `url('../media/bg-lidong.jpg') center/cover` | 画布底（淡蓝雪景+树枝+雪花+雪坡） |
| `--accent` | `#B8863E` | 暖金/赭石点缀（kicker、序号、pinyin、lead 强调） |
| `--ink` | `#2C4A6E` | 正文深蓝墨（封面大标题与卡内正文） |
| `--gray` | `#6B88A6` | 次要灰蓝（副标题、页眉脚注） |
| `--cream` | `rgba(244,249,252,.55)` | 内容卡半透浅冰蓝浮层（保证长文可读） |
| `--edge` | `rgba(44,74,110,.25)` | 卡片细边 |
| `--highlight` | `rgba(233,180,69,.30)` | 正文重点短语的暖金荧光笔底色 |
| 外层文字 | 深蓝 `#2C4A6E` / 灰蓝 `#6B88A6` | 浅底深字 |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体
- 封面大标题偏宋体加粗、字距放宽，配一行 Didot/拼音英文小字

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置 top:190/bottom:136、三处间距 h1:34/sub:24/body:16、foot 吸底等均同 `green-editorial`
- 背景使用垫图 `media/bg-lidong.jpg`（封面与内容页同图，整套背景统一）；封面无蒙层、无卡片浮层，文字直接压雪景上半部分
