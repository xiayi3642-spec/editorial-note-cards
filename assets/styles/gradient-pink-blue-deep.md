# 风格：粉蓝紫深调渐变（可选风格）

- 名称：`gradient-pink-blue-deep`
- 默认：否（用户给粉/蓝/紫系渐变参考图，或点名「粉蓝紫深调」时使用）
- 来源参考色：`#FFCEE3`（浅粉）、`#678EC9`（蓝）、`#262277`（深蓝紫）—— 深调延伸
- 氛围：深邃蓝紫 —— 左下浅紫 → 右上深蓝紫 对角渐变 + 奶油卡浮层，与绿色 Editorial 同构
- 文字明暗：**右上深色区 → 外层文字与描边固定用白；内容卡浅底 → 正文用深色；左下浅区页脚用深色**

## 色板（按 7:2:1 + 同色系深调延伸）
| token | 值 | 用途 |
|---|---|---|
| 背景对角渐变 | `linear-gradient(to top right,#D9C4F2 0%,#9A86E8 30%,#5B48B0 55%,#37257F 78%,#1E1750 100%)` | 画布底，左下浅→右上深 |
| `--accent` | `#9A86E8` | 亮紫强调（kicker、序号、lead、quote 边） |
| `--ink` | `#1E1750` | 正文深蓝紫（卡内浅底深字） |
| `--gray` | `#7A76A6` | 次要灰 |
| `--cream` | `#F3EFFB` | 卡片底（偏紫白） |
| `--edge` | `#5B48B0` | 卡片紫细边 |
| 外层文字/描边 | 白 `#fff` / `rgba(255,255,255,.5~.9)` | 右上深区固定白（frame/t1/t2/rule）；左下浅区页脚用 `#1E1750` |

## 字体栈
- 与 `green-editorial` 相同：Noto Serif SC / Playfair Display / IBM Plex Mono / Noto Sans SC；全局去斜体

## 结构（与所有风格共用，勿改）
- 画幅 1080×1440；外层框、卡片位置、三处间距、foot 吸底等均同 `green-editorial`
